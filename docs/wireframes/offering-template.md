# Wireframe — Offering detail (template)

**URL:** `/offerings/[slug]`  
**CMS:** One template for all services (group training, restore, yoga, etc.)

---

## Header / footer

Same global chrome as [home.md](home.md).

---

## Section 1 — Hero

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    [ HERO IMAGE OR SHORT LOOP VIDEO ]                       │
│                                                                             │
│  H1: {Offering title}  e.g. Group Training                                  │
│  Sub: {One-line summary}                                                    │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## Section 2 — Description

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  Body copy (2–4 paragraphs from CMS)                                        │
│  — What it is                                                               │
│  — Who it's for                                                             │
│  — How it fits the journey                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## Section 3 — What's included (bullets)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  H2: What's included                                                        │
│  • Bullet 1                                                                 │
│  • Bullet 2                                                                 │
│  • Capacity note (e.g. max 24 per session) — if applicable                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## Section 4 — CTA band

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  [ View schedule ─────────────────────────────► ]  → /schedule               │
│  [ Buy credits ───────────────────────────────► ]  → /buy (optional 2nd)   │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## Section 5 — Related offerings (optional)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  H2: Explore more                                                           │
│  [ Card ] [ Card ] [ Card ]  → other /offerings/*                           │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
[ Inquire about private training ─────────────► ]  → mailto or form
```
