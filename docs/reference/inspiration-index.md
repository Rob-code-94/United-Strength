## Tier definitions (client labels)

| Tier | Label | Role for United Strength |
|------|-------|--------------------------|
| **1** | Closest to the United Strength feeling | Primary visual and cultural north star |
| **2** | Private club / membership | Membership model, application flow, club positioning |
| **3** | Editorial / design / culture | Typography, pacing, photography, editorial layout |
| **4** | Hospitality / experience / wellness | Warmth, standards, cinematic experience, wellness tone |
| **5** | Membership experience / community model | Simplicity, community, creative membership UX |
| **+** | Additional references | Selective borrow — features, craft, or brand discipline |
